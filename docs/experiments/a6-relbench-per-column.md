# A6 — ручная per-column карта RelBench

## Статус

`in_process; not_finished`. Подготовлен полный пакет
из 179 полей: 50 для `rel-stack` и 129 для `rel-event`. Две требуемые
независимые человеческие разметки ещё не выполнены, поэтому A6 не считается
закрытым, а A7 пока не разблокирован.

## Что подготовлено

- зафиксирован перечень всех столбцов и табличных временных каналов;
- созданы две одинаковые пустые формы для независимых аннотаторов;
- отдельно создана bootstrap-карта по исходному коду загрузчика; она не
  считается голосом и скрывается от аннотаторов до сдачи обеих форм;
- реализована проверка полноты, Cohen's kappa по основному классу, точное
  согласие по тройке `(класс, временной столбец, граница)` и выгрузка
  расхождений для adjudication.

## Предварительный аудит источника

Загрузчик RelBench 2.1.2 уже удаляет из `rel-stack` ряд очевидных snapshot-
полей: счётчики и репутацию пользователей, агрегированные счётчики постов,
даты последнего редактирования/активности, score и другие поля. Это снижает,
но не устраняет риск. В bootstrap-карте как `unknown` оставлены mutable-поля
профиля пользователя и содержимое текущего snapshot поста, потому что время
последнего изменения отдельных значений отсутствует.

В `rel-event` особого внимания требуют две зоны: `user_friends` вообще не
имеет времени ребра, а `event_attendees.status` имеет только время начала
события, не время появления/изменения RSVP. Для таких случаев аннотаторы
должны оценивать именно доступность значения, а не автоматически копировать
табличный `time_col`.

## Критерий завершения

1. Два подходящих соавтора независимо заполняют формы, не видя bootstrap.
2. Рассчитываются kappa и exact agreement.
3. Расхождения разрешаются отдельным adjudication.
4. Итоговая карта получает версию и только после этого передаётся в A7/B1.

Текущий автоматический контроль закономерно возвращает `not_ready`: 0 из 179
полей заполнены обоими аннотаторами.

## Model-assisted разметка

Выполнена полная предварительная разметка 179/179 полей. Это отдельный
model-assisted результат, а не подмена двух человеческих голосов. Для
операционного использования применено консервативное правило: столбцы без
проверяемого времени получают `unknown` и `exclude`; допустимые временные
прокси сохраняются с явным флагом низкой или средней уверенности.

Эту карту можно использовать для технического черновика A7, но результат
нельзя называть основным RQ0 на RelBench до независимой проверки двумя
аннотаторами и разрешения расхождений.
