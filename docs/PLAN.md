# PITBULL — реестр статусов по плану FSE 2027

Это не отдельный план — это статусный реестр поверх уже существующего плана
`proposals/fse2027_proposal.md` (ревизия 5, финальная). Источник истины по
содержанию — сам proposal и `proposals/principles.md`; этот файл только
отслеживает, что из §3/§4/§9 сделано, кем и в каком состоянии, чтобы
несколько соавторов (и агент по команде `/continue`) не дублировали работу.

**Важное отличие от шаблона, из которого этот файл адаптирован:** здесь нет
атомарного захвата шагов пушем в общую ветку и нет авто-мержа — статусы
правятся руками (или локально агентом, как часть предлагаемого диффа) и
проверяются человеком перед коммитом. Причины — в `.claude/commands/continue.md`.

**Правило ярусов остаётся в силе** (proposal, шапка): после 3 сентября в
ярусы A и B ничего не добавляется, только убирается; порядок между ярусами
(A → B → C) и порядок дедлайнов (§9) — обязательны, порядок задач ВНУТРИ
яруса — по зависимостям ниже.

**Правило результатов** (адаптировано из вынесенного шаблона, согласуется с
`pilot/REPORT.md` — так пилот уже писался): любой RQ/эксперимент, у которого
есть done-when с числом или вердиктом, обязан приземлиться отчётом в
`docs/experiments/<id>-<slug>.md` — вопрос, метод и команда воспроизведения,
предрегистрированное правило решения, данные, вердикт `positive | neutral |
negative`, вывод. Отрицательный или нейтральный результат — тоже готовый
отчёт, не повод молчать (см. пилот F0=1/12 — ровно такой случай). Шаг с
эмпирическим done-when не помечается `done`, пока отчёта нет.

## Формат шага

```
### <id> — <заголовок>
- status: todo | in_progress | in_review | done | blocked
- owner: —
- deps: <id> <id> | —
- source: <раздел плана/критики, который мотивирует шаг>
- done-when: <конкретный, проверяемый критерий>
```

`in_review` значит: работа сделана и лежит в рабочем дереве или в локальном
коммите на отдельной ветке, но не смёржена и не признана человеком
завершённой — в отличие от исходного шаблона, здесь это не «PR открыт»
(здесь нет автономного PR-цикла), а «ждёт вашего разбора».
